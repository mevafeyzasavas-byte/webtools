# Web Tools APK
Uygulama, `APP_URL` adresindeki sayfayı WebView'de açar. Sayfayı sunucuda güncellediğinde APK'yı yeniden kurman gerekmez.
APK yalnızca ikon, ad veya adres değişince yeniden derlenir (Actions > "APK derle" > Run workflow).
Adres: repo Settings > Secrets and variables > Actions > Variables > `APP_URL`.
